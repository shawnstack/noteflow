# NoteFlow 功能缺口设计

> 2026-09-28 · 只设计，不改代码。对象是当前仓库（`package.json` 0.3.0，关于页与 README 自称 v1.2）。
> 更完整的评审与行号证据见 [DESIGN.md](./DESIGN.md)，差距图见 [gap-map.svg](./gap-map.svg)。本文是收束后的缺口说明：补什么、不补什么、按什么顺序。

定位不变：**单机、单人、笔记就是 `notes/` 里的文件，AI 可以读写，但默认要人批准。** 不是 Notion，也不是 Obsidian 全家桶。

功能完整不等于功能多。专业感来自三件事：已有功能没有半成品、高频路径键盘可达、破坏性操作可撤销。

## 1. 技术栈：保持不动

| 层 | 现状 | 结论 |
|---|---|---|
| 前端 | React 19.2、TypeScript 6、Vite 8、Tailwind 4 | 不换框架，不加状态库 |
| 视觉 | QuickForge 语义 token + `quickforge-surface.css` | 继续对齐，不自造第二套设计系统 |
| 后端 | 无自有业务服务。`server.mjs` 只启动并反代专属 QuickForge（5178，数据 `~/.noteflow`） | 不新建数据库，不新建笔记 API |
| 笔记 | `notes/` 目录中的文件。读 `GET /api/workspace/file`，写 `tools/write_file` | 笔记就是文件，继续如此 |
| AI | 客户端会话 + `POST /api/agents/:id` + 全局 SSE；`surface-agent.ts` 包成 ChatSurface 的 Agent | 适配层边界保持 |
| 聊天 UI | `src/components/chat/surface/` 源码快照 | 升级仍手动同步；能不改快照就不改 |
| 预览依赖 | pdfjs-dist、docx-preview、xlsx、jszip 已安装；`artifactPreviewMode()` 已三分流 | 中栏接线即可，不新引入解析器 |
| 编辑器 | 中栏是 textarea | 先做零依赖按键增强。不上 Monaco。CodeMirror 只留作以后评估 |

增量只允许落在现有接口上：`workspace/children`、`workspace/file`、`workspace/search`、`grep_files`、`write_file`、`run_command`。

## 2. 已经有的，不再重做

- 三栏：左树、中栏阅读 / 编辑 / 分屏、右栏对话。拖拽调宽，左右可折叠。
- 文件：懒加载树、新建笔记（可带子目录）、新建文件夹、刷新、重命名、移入 `.trash/`、从回收站恢复。
- 编辑：GFM、Mermaid、Markdown 工具栏、中文字数、`⌘S`、localStorage 草稿、外部 mtime 冲突提示。
- 搜索：`⌘P`，文件名与全文两种模式，全文结果带行号预览。
- 对话：多会话、模型切换、写保护审批、附带当前笔记（截断 8000 字）、停止生成、思考块、工具卡、附件粘贴。
- 设置：默认模型、OpenAI 兼容服务商、写保护与附带笔记的默认值、消息字号 14–17。
- 反馈：确认 / 输入弹窗、Toast、错误边界。快捷键 `⌘P` `⌘N` `⌘S` `Esc`。

附件发送这一条比表面看的完整：`toUserMessage` 会把图片块和文档抽取文本并进 `content` 再 POST。缺口不在「字段被丢掉」，而在中栏没有复用同一套预览。

## 3. UI 交互原则

1. **三栏职责不变。** 树负责找，中栏负责读和改，右栏负责问。不增加第四栏。大纲、反链、历史都用浮层，不常驻。
2. **一个主动作，其余收进菜单或快捷键。** 顶栏继续是搜索、新建、折叠、设置。
3. **破坏性操作走现有确认框。** 删除、覆盖、放弃未保存、运行危险命令用 `showConfirm`。普通保存和切换模式不弹。
4. **状态安静。** 未保存用脏标记；保存成功不 Toast。失败、冲突、恢复草稿才提示。
5. **桌面优先，中文界面。** 宽度不够时收起左右栏，不重做移动端，不做底部导航。
6. **AI 不抢编辑权。** 默认写保护。审批要能看见差异，而不是只看见一段 JSON。干净文件的外部写入继续静默刷新，脏文件继续二选一。

## 4. 体验断点

这些是现在走不顺的路径，不是新功能清单。证据与 [DESIGN.md](./DESIGN.md) 附录 C 一致，本轮又核对了选中样式、搜索 Enter、预览分支和附件合并。

| 断点 | 现在怎样 | 用户感受 |
|---|---|---|
| 当前文件看不出来 | `WorkspaceFileTree` 里 `isSelected ? '' : ''` | 点开笔记后树没有落点 |
| 树不能管理文件 | 重命名、回收站只在中栏当前文件上 | 整理目录要先打开再绕到工具栏 |
| 回收站像普通目录 | `.trash/` 与笔记混排；恢复不保证原路径；UI 不能彻底删除 | 「可恢复」不可靠 |
| 未保存会丢 | 新建只记住路径，不立刻写文件；切换文件无拦截；无 `beforeunload` | 没按 `⌘S` 就换文件，内容消失 |
| 编辑是裸文本框 | 无 Tab 缩进、无 `⌘B` / `⌘I`、列表回车不续行 | 工具栏有的格式，键盘路径没有 |
| 搜索不能选 | Enter 永远打开第一条；方向键无效；全文虽有行号但不定位 | `⌘P` 像半个面板 |
| 中栏预览判错类型 | `isBrowserPreviewablePath` 含 html，中栏分支一律 `<img>` | html 显示成碎图；PDF / Word / Excel 打不开，尽管依赖和分流函数已经在 |
| 审批是盲批 | 审批卡只展示截断后的参数 JSON | 写保护这个核心差异点，批准前看不到改了什么 |
| AI 只有单向 | 笔记能附给模型；模型回复不能插回当前笔记 | 闭环停在复制粘贴 |
| 会话不好认 | 标题固定，不能改名；列表点外面不收起 | 多条对话长得一样 |
| 栏宽不记住 | 宽度和折叠只活在这次会话 | 每次打开都要再拖 |
| 版本号三处不一致 | `package.json` 0.3.0 / 关于页 v1.2 / README 标题 | 关于页不可信 |

## 5. 建议补齐的功能

四组。每一组都是把现有三栏补完整。

### 5.1 笔记基本盘

**未保存不再静默丢失。** 切换文件时若有脏内容，确认框给出「保存并切换 / 放弃 / 取消」。关闭页签走 `beforeunload`。`⌘N` 确认文件名后立刻写入空文件，取消则什么都不创建。

**短延迟自动保存，保留 `⌘S`。** 停止输入约 1 秒后写入。写之前再读 mtime：没变就写；变了就沿用现在的冲突条，不静默覆盖。状态放在字数旁边：保存中、已保存、失败。成功落盘后清掉该路径草稿。

**文件树补三个基本动作。** 选中行用现有 accent 样式高亮。右键菜单：新建笔记、新建文件夹、重命名、移入回收站、复制路径。重命名沿用现在的行内输入。不做拖拽排序，避免和调栏宽抢指针。

**回收站仍是 `.trash/`，但不当成普通文件夹。** 树里单独收起。移入时放进 `时间戳/原相对路径`，这样恢复能回到原处，也不怕同名覆盖。原处已有文件时询问覆盖或改名。彻底删除只出现在回收站条目上，二次确认。不提供「清空全部」。

**编辑器只加高频按键。** Tab / Shift+Tab 缩进，`⌘B` `⌘I` `⌘K` 复用工具栏包裹，列表行回车续写、空项回车退出。撤销重做用文本框自身历史。不替换成块编辑器。

**中栏预览改走已有分流。** `artifactPreviewMode()`：html 用带 `sandbox` 的 iframe，pdf / docx / xlsx 复用聊天侧只读预览，图片维持 `<img>`。不能预览的二进制说明原因，不假装能编辑。

**阅读模式大纲用弹出列表。** 从标题生成，点击滚动，不常驻、不做成第四栏。

### 5.2 搜索

把 `⌘P` 补完，不另做搜索页。

- 上下键移动，Enter 打开当前条，Esc 关闭。
- 文件名结果里的目录不能当笔记打开。
- 全文结果打开后滚到该行并短暂高亮；编辑模式把光标放上去。
- 命中词用 `<mark>` 标出。空查询时显示本次会话最近打开，只存在内存或 localStorage，不建索引。
- 结果仍大约 100 条。继续用服务端 `grep_files`。

### 5.3 右栏：把已承诺的闭环补完

- **审批前能看 diff。** `write_file` 用现成 `diff-view` 显示增删，默认折叠，标题给出 ±行数。新文件显示「新建」。批准 / 拒绝按钮不变。
- **回复可以回到笔记。** 消息上提供「插入到文末」。当前正在编辑时追加到草稿并标脏；没有打开笔记时询问文件名再落盘。不自动覆盖选区。
- **会话能认出自己。** 列表里改名。若服务端没有改标题接口，用 localStorage 记 sessionId → 标题，不改 QuickForge。点击外部关闭列表，复用模型菜单那层遮罩。
- **整条回复可复制。** 与「插入」放在同一行，不新开工具栏。
- **写保护说清楚。** 设置里的开关只影响新对话。盾牌只表示当前会话。文案用「此对话：写保护开 / 关」。
- **附带笔记保持 8000 字。** 开关旁写明是否已截断。不把整个笔记库塞进上下文。

`ask_user` 若当前适配层会丢事件，用现有输入弹窗接一条回答即可。goal / todo / subagent / generate-image 的专属卡片继续不做，沿用默认渲染。

### 5.4 壳子

- 栏宽、左右折叠、上次打开的文件写入一个 localStorage key。
- 视口变窄时先收右栏、再收左栏，中栏始终可读。
- 空笔记、空搜索、启动失败的文案统一中文。
- 关于页版本跟 `package.json`，README 的「已知限制」标题跟着改。
- 错误边界去掉 zinc 硬编码，改用同一套语义色。
- 顺手清掉无人引用的旧 `Markdown.tsx`，以及 vite 配置里过时的 zhibi 注释。这是清理，不是功能。

## 6. 明确不做

| 不做 | 原因 |
|---|---|
| 双链图谱、块级引用、数据库表格 | 会把纯 Markdown 文件变成另一种产品；反链列表若以后要做，用 `grep_files` 即可，不进本次 |
| 标签体系、frontmatter 数据库、每日笔记日历、模板库 | 与「把现有路径走顺」无关，单独立项 |
| 自建同步、账号、协作、原生 App | 和本地文件架构冲突，等于重写 |
| 语义搜索、跨库 RAG、全文索引服务 | 附带上下文必须由用户显式打开当前笔记 |
| 主题市场、多语言设置、插件 | 语义色跟随 QuickForge；聊天词条里已有中英，没有设置入口也不本次补 |
| 搬入 git 面板、goal / todo 面板、桌面版 hooks | 快照里有 API 不代表 NoteFlow 要变成 IDE |
| 版本时光机、远程 push / pull | 回收站加冲突条足够；凭据管理不做 |
| WYSIWYG、Monaco、多标签工作区 | 保持「Markdown 源文 + 预览」，这和 AI 改源文最匹配 |
| AI 全自动批量改写 | 会抵消写保护这个核心差异 |
| 中栏编辑 PDF / Office | 只预览 |

暗色切换、语言切换、服务商列表编辑删除、分屏滚动同步、阅读模式 KaTeX、快捷键表（`⌘,` `⌘E`），都有现成基础，但不是当前断点。放到 P2 之后看反馈，不写进本轮交付。

## 7. 落地顺序

每一段都能单独交付，且不改架构。

| 顺序 | 内容 | 验收时能看到 |
|---|---|---|
| P0 | 选中高亮；未保存拦截与新建落盘；搜索方向键且目录不当笔记、全文跳行；预览分流（html / PDF / Office）；栏宽记忆；审批 diff；回复插入文末；会话改名与点外关闭；版本号单一来源 | 换文件会询问；`⌘P` 能选中并跳到行；html 不再走 `<img>`；批准前能看到行级差异；刷新后栏宽还在 |
| P1 | 树右键菜单；回收站按原路径恢复与彻底删除；自动保存且冲突不覆盖；Tab / `⌘B` / 列表续行；阅读大纲浮层；写保护文案拆开；空态中文 | 子目录笔记删除后能回到原子目录；停止输入后文件更新；冲突条仍会出现 |
| P2 | 最近打开；命中高亮；窄屏收栏；错误边界语义色；死代码清理 | 不影响 P0/P1 即可停 |

P0 是把半成品补完。P1 才动文件生命周期和编辑手感。P2 是完整度。

## 8. 实现时的边界

真做的时候仍沿用 `src/lib/api.ts` 与现有弹窗，不新增服务端路由，不重写 ChatSurface。回收站用目录保留原路径，不用 sidecar 数据库。插入笔记只追加草稿，保存仍走现有冲突检测。审批 diff 只读，不在卡片里直接改内容。
